# 👁️ Eye Project (P01)
### "Saving Lives through Localized Intelligence"

이 프로젝트는 사회적 약자(어린이, 노약자)의 안전을 위해 **30일간의 로컬 흔적 보존**을 구현하는 시각 안전망 시스템입니다.

## ✨ Key Philosophy
- **Privacy First**: 모든 데이터는 중앙 서버가 아닌 로컬 기기에만 저장됩니다.
- **30-Day Retention**: 실종 방지를 위해 30일간의 흔적을 기록하며, 이후 자동 삭제됩니다.
- **Eco-system Integration**: 주변 IoT 기기와의 상호작용을 통해 골든타임을 확보합니다.
